# Language Practice（TOEIC・フランス語 練習アプリ）

ブラウザだけで動く語学練習アプリ（ビルド不要の静的サイト）。TOEIC（英語）とフランス語の
四択クイズ、10分版、ディクテーション（書き取り）練習ができ、成績を蓄積して
得意・苦手分野を分析します。

**公開ページ:** （GitHub Pages 有効化後にURLが入ります）

## 機能

- **四択クイズ**：TOEIC Vol.1〜7（222問）、フランス語 Vol.F1〜F2（64問）。
  セット全体の制限時間つき、終了後に解答・解説を表示。
- **10分版**：各セットを「文法／読解」などに分割して約10分で挑戦。
- **ディクテーション**：音声（ブラウザTTS）を聞いて書き取り。空欄埋め／全文タイプ、
  ▶再生・🐢ゆっくり再生・答えを見る。採点はやさしめ（アクサン違いや軽微なミスは正解）。
  Enterキーで「答え合わせ→次へ」と進める。
- **苦手分析**：カテゴリ別の正答率、弱点復習、ディクテーションの「よくつまずく語」など。

## 使い方

`index.html` をブラウザ（Safari / Chrome 推奨）で開くだけ。
音声を使うディクテーションは、音の出るブラウザで開いてください。

## 成績データの保存について

- 成績・分析は各ブラウザの **localStorage** に保存されます。**同じ端末の同じブラウザ**で
  開く限り消えません。
- 端末・ブラウザをまたぐ自動同期はありません。別端末へ移すときやバックアップには、
  各画面の「データ書き出し／読み込み」（JSON）を使ってください。

## 開発

- 依存なしの素の HTML/CSS/JS（ES modules 不使用）。
- ロジックのテスト: `node tests/run-tests.js`
