# Language Practice（TOEIC・フランス語 練習アプリ）

ブラウザだけで動く語学練習アプリ（ビルド不要の静的サイト）。TOEIC（英語）とフランス語の
四択クイズ、10分版、ディクテーション（書き取り）練習ができ、成績を蓄積して
得意・苦手分野を分析します。

**公開ページ:** https://aratama-ship-it.github.io/language-practice/

## 機能

- **四択クイズ**：TOEIC Vol.1〜7（222問）、フランス語 Vol.F1〜F2（64問）。
  セット全体の制限時間つき、終了後に解答・解説を表示。
- **10分版**：各セットを「文法／読解」などに分割して約10分で挑戦。
- **ディクテーション**：音声（ブラウザTTS）を聞いて書き取り。空欄埋め／全文タイプ、
  ▶再生・🐢ゆっくり再生・答えを見る。採点はやさしめ（アクサン違いや軽微なミスは正解）。
  Enterキーで「答え合わせ→次へ」と進める。
- **苦手分析**：カテゴリ別の正答率、弱点復習、ディクテーションの「よくつまずく語」など。

## 使い方

`index.html` をブラウザ（Safari / Chrome 推奨）で開くだけ。
音声を使うディクテーションは、音の出るブラウザで開いてください。

## 成績データの保存について

- 成績・分析は各ブラウザの **localStorage** に保存されます。**同じ端末の同じブラウザ**で
  開く限り消えません。
- 端末・ブラウザをまたぐ自動同期はありません。別端末へ移すときやバックアップには、
  各画面の「データ書き出し／読み込み」（JSON）を使ってください。

## iPhone / Android のホーム画面に追加する（PWA）

公開URL <https://aratama-ship-it.github.io/language-practice/> を開き、

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー → 「アプリをインストール」

追加後はアドレスバー無しの全画面で起動し、**オフラインでも全問題が解けます**（初回だけ通信が必要）。

音が出ないときは、まず **iPhone本体のサイレントスイッチ**を確認してください。
iOSではブラウザの音声合成がサイレントスイッチの影響を受けることがあります。

### 学習リマインダー

ホーム画面の「学習リマインダー」から曜日・時刻を選び、「カレンダーに追加」を押すと、
**iPhone標準のカレンダーに繰り返しの予定＋アラーム**として登録されます。
通知はカレンダーが出すので、このアプリを開いていなくても届きます。やめるときは予定を削除。

Web Push（サーバーから送る通知）は使っていません。iOSにはWebアプリが時刻を指定して
自前で通知を予約する手段が無く（Notification Triggers API は Safari 未対応）、
このアプリはサーバーを持たない静的サイトのためです。

### ディクテーションの入力設定

セット選択画面の「入力欄に自動でカーソルを合わせる」で切り替えます。
**タッチ端末では既定オフ**（問題を出した瞬間にキーボードが出るのを防ぐため）、PCでは既定オン。
入力欄のフォントは16px以上を維持すること。**16px未満にするとiOSがフォーカス時に自動ズームします。**

## 開発

- 依存なしの素の HTML/CSS/JS（ES modules 不使用）。
- ロジックのテスト: `node tests/run-tests.js`

### Vol（問題セット）を追加するとき

触る場所は**4か所**。1つでも漏れるとテストが落ちるか、本番だけ問題が出ない。

1. `js/data/volN.js` を作る
2. `index.html` に `<script src="js/data/volN.js">` を1行足す
3. `tests/run-tests.js` の `DATA_FILES` に追加する
4. `tests/run-tests.js` の `EXPECTED.toeic` に `N: 問題数` を追加する

**正解の位置は (A)〜(D) に散らすこと。** アプリは選択肢をシャッフルしないため、
正解が偏っていると位置で当てられてしまい練習にならない。偏りは
`tests/run-tests.js` の `answer-balance` が検出する（どれか1つの位置が15%未満だと失敗）。

均すには保守ツールを使う:

```
node tools/rebalance-answers.js js/data/volN.js
```

**ただし TOEIC Vol.1〜6 には実行しないこと。** 市販教材の原本から起こしたセットで、
解説に「原本の【正解修正】により (B) が正しい」など原本の選択肢記号を参照する注記があり、
並べ替えると出典との対応が壊れる。この6つはテストの例外リストに入れてある
（偏りが残っていることを承知のうえで対象外にしている）。
ツール側にも安全装置があり、解説に (A)〜(D) の記号参照が1つでも残っていれば実行を中止する。

Part 5 のみのVolは10分版が「前半/後半」、Part 5 以外を含むVolは「文法/読解」に分かれる。
実態に合わないときは Vol 定義に `halfLabels: { grammar: "...", reading: "..." }` を書けば
ボタンの表記を差し替えられる（問題数は自動で後ろに付く）。

### PWAの更新手順（重要）

`sw.js` は **生成物**。手で編集しないこと。配信ファイルを1つでも変えたら:

```
node tools/build-sw.js   # 全配信ファイルのSHA-256から自動でバージョンを振り直す
node tests/run-tests.js  # sw.js の再生成忘れ・参照漏れをここで検出する
```

を実行してからコミットする。実行を忘れると、利用者の端末に古いキャッシュが残り続ける。
バージョン番号を手で上げる箇所は無い（上げ忘れを構造的に防ぐため）。

アイコンを変えるときは `python3 tools/make-icons.py`（依存は Pillow のみ）。
`icons/_preview.png` は目視確認用で、配信もコミットもしない。
