# TOEIC Reading 練習ウェブアプリ 設計書

作成日: 2026-07-03
承認: ユーザー承認済み（2026-07-03）

## 目的

既存のTOEIC教材テキスト（`app-dev/TOEIC_Practice/` の Vol.1〜6、全190問）を、
ブラウザだけで挑戦できるボタン選択式・時間制限ありのウェブアプリにする。
全問挑戦後に解答・解説を確認でき、成績を蓄積して得意・苦手分野を解析できる。

## 技術構成

- **静的アプリ**: `apps/language-app/toeic-webapp/` に配置。`index.html` をブラウザで開くだけで動作（サーバー・ビルド不要）
- ファイル構成:
  - `index.html` — エントリポイント
  - `css/style.css` — スタイル
  - `js/app.js` — 画面制御・タイマー・採点ロジック
  - `js/storage.js` — localStorage の読み書き・JSON書き出し/読み込み
  - `js/analysis.js` — カテゴリ別集計・弱点解析
  - `js/data/vol1.js` 〜 `vol6.js` — 問題データ（グローバル変数として登録、file:// で動作させるため ES modules は使わない）
- iCloud フォルダに置くため、どの Mac からも同じファイルで利用可能（成績は各ブラウザの localStorage に保存される点に注意）

## 問題データ

### 変換元と問題数

| Vol | ファイル | 構成 | 問題数 |
|-----|---------|------|--------|
| 1 | TOEIC_Reading_Practice.txt | Part5×20 / Part6×4 / Part7×8 | 32 |
| 2 | TOEIC_Reading_Practice_Vol2.txt | 同上 | 32 |
| 3 | TOEIC_Reading_Practice_Vol3.txt | 同上 | 32 |
| 4 | TOEIC_Reading_Practice_Vol4_前置詞特化.txt | Part5形式×30 | 30 |
| 5 | TOEIC_Reading_Practice_Vol5.txt | Part5×20 / Part6×4 / Part7×8 | 32 |

合計 190問。**Vol.5・Vol.6 には解答・解説が原本に存在しないため、変換時に新規作成する**（計64問分）。

### データ形式

```js
// 各問題オブジェクト
{
  id: "v1-q3",           // vol番号-問題番号
  vol: 1,
  part: 5,               // 5 | 6 | 7
  passageId: "v1-p1",    // Part 6/7 のみ。Part 5 は null
  number: 3,             // Vol内の通し番号
  question: "The new policy will take ------- on January 1st of next year.",
  choices: ["effect", "affect", "effort", "offer"],  // A,B,C,D の順
  answer: 0,             // 正解のインデックス (0=A)
  explanation: "take effect = 「発効する・効力を持つ」慣用句。※ affect は動詞「影響を与える」",
  category: "前置詞・慣用表現"
}

// Part 6/7 の文書
{
  id: "v1-p1",
  vol: 1,
  part: 6,
  title: "Questions 21-24 refer to the following e-mail.",
  body: "To: All Staff\nFrom: ..."   // 整形済みテキスト（改行保持）
}
```

### カテゴリ（成績記録.txt の弱点分析を踏襲）

1. 前置詞・慣用表現
2. 動詞の形・時制
3. 品詞判断
4. 構文・接続詞
5. 語彙
6. 文脈把握（Part 6 の文挿入など）
7. 読解（Part 7）

## 画面構成（SPA、4画面）

### 1. ホーム
- Vol.1〜6 の一覧カード（受験回数・最高スコア・前回スコアを表示）
- 「弱点復習」ボタン → 復習設定へ
- 「成績分析」ボタン → 分析画面へ
- データ書き出し（JSONダウンロード）／読み込み（ファイル選択）ボタン
- テスト開始前に制限時間を選択（デフォルト: 32問=20分、Vol.4=15分。10〜40分で変更可）

### 2. テスト画面
- ヘッダー: 残り時間カウントダウン、進捗表示（Q5 / 32）
- Part 6/7 は文書を上部に表示し、その下に設問
- (A)〜(D) の選択ボタン。選択済みは強調表示、選び直し可
- 「前へ」「次へ」で全問を自由に行き来できる（本番同様の見直し可）
- 問題番号ナビ（回答済み/未回答が一目でわかる）
- 「採点する」ボタンで終了（未回答があれば確認ダイアログ）
- **時間切れで自動採点**。残り3分でタイマーを警告色に
- 中断ボタン（確認ダイアログあり。中断したセッションは保存しない）

### 3. 結果画面
- 総合スコア（正解数/問題数、正答率）
- Part別・カテゴリ別の正答率バー
- 全問リスト（○×表示）→ タップで展開し、問題文・自分の解答・正解・解説を表示
- 「ホームへ」「もう一度」ボタン

### 4. 分析画面
- 全履歴を集計したカテゴリ別正答率グラフ（横バー、試行数も表示）
- 苦手カテゴリランキング（正答率の低い順）
- セッション履歴（日時・Vol/モード・スコアの一覧、正答率の推移）
- 「苦手カテゴリを復習する」ボタン → そのカテゴリで復習モードを開始

## 弱点復習モード

- 出題ソースを選択:
  - **間違えた問題から**: 過去セッションで誤答した問題（直近の解答が誤答のもの優先）
  - **カテゴリ指定**: 7カテゴリから選択
- 問題数を選択: 10問 / 20問 / 全部
- 制限時間: 問題数 × 40秒
- 結果は通常セッションと同様に記録・解析対象とする

## データ保存（localStorage）

```js
// キー: "toeic-app-data"
{
  version: 1,
  sessions: [
    {
      id: "2026-07-03T10:00:00",
      date: "2026-07-03T10:00:00+09:00",
      mode: "vol",              // "vol" | "review-wrong" | "review-category"
      volId: 1,                  // vol モードのみ
      category: null,            // review-category のみ
      timeLimitSec: 1200,
      timeUsedSec: 1050,
      answers: [
        { qid: "v1-q1", chosen: 0, correct: true },
        { qid: "v1-q2", chosen: 2, correct: false },
        // 未回答は chosen: null, correct: false
      ]
    }
  ]
}
```

- セッション完了（採点）時に自動保存
- 書き出し: 上記JSONをそのままダウンロード。読み込み: バリデーション後に置き換え（確認ダイアログあり）
- localStorage が使えない環境では警告バナーを表示し、採点・解説機能のみ動作（記録されない）

## エラー処理

- 読み込みJSONの形式不正 → エラーメッセージを出し、既存データは変更しない
- localStorage 容量超過 → 保存失敗を通知し、書き出しを促す
- タイマーはタブ非アクティブでも実時間基準で進行（Date.now() 基準で残り時間を計算）

## 検証

1. 変換後の問題数チェック: 32+32+32+30+32+32 = 190 を機械的に確認

3. Vol.5・6 の新規解説は全問レビュー
4. ブラウザで1セット通しの動作確認（選択→移動→採点→解説表示→再挑戦→分析画面）
5. タイマー切れの自動採点、書き出し/読み込みの往復を確認
